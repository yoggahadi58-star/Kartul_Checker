# Kartul_Checker
Kartul_Checker_Site_Fitur_Lengkap_v5

**KartulChecker Pro** adalah platform berbasis web yang dirancang untuk mempermudah verifikasi, validasi, dan pengelolaan data/dokumen Karya Tulis secara efisien, cepat, dan terintegrasi.

---

## 💡 Fitur Utama

* **Automatic Verification:** Pengecekan data dan format dokumen secara otomatis.
* **Comprehensive Analytics:** Dasbor statistik lengkap untuk memantau status pemeriksaan.
* **Modern & Clean UI:** Antarmuka pengguna yang responsif, rapi, dan intuitif.
* **Format Support:** Mendukung berbagai format file (pdf,doc)
* **Export & Reporting:** Fitur unduh laporan hasil pengecekan dalam satu klik.
